# CamWall

Мінімалістична вебвідеостіна для RTSP-камер на Debian / Armbian. FFmpeg читає RTSP і передає MPEG-TS через WebSocket, а браузер відтворює потік через mpegts.js / Media Source Extensions.

## Можливості

- Адаптивна сітка камер, пошук, обрані камери та повноекранний режим браузера.
- Додавання, редагування та видалення камер через вебналаштування.
- Окремі конфігураційні файли: `playlist.json` для камер і `settings.json` для інтерфейсу.
- Один FFmpeg-процес на камеру, спільний для кількох глядачів.
- Серверне зменшення роздільності/FPS і перекодування в H.264.
- systemd-сервіс без Docker і бази даних.

## Встановлення з нуля

Потрібен Debian або Armbian із доступом до репозиторіїв пакетів та GitHub:

```bash
git clone https://github.com/ZoNier/camwall.git
cd camwall
sudo bash install.sh
```

Інсталятор встановить залежності, створить системного користувача `camwall`, Python venv, systemd-службу та запустить застосунок.

Відкрий `http://IP_СЕРВЕРА:8080`.

## Повторне встановлення

Щоб перевстановити застосунок і **зберегти список камер та налаштування**:

```bash
cd camwall
sudo bash /opt/camwall/uninstall.sh
sudo bash install.sh
```

Скрипт видалення зупинить службу та видалить код і віртуальне середовище, але залишить:

- `/opt/camwall/playlist.json`
- `/opt/camwall/settings.json`

Під час повторного встановлення ці файли не перезаписуються.

Щоб видалити **все, включно з конфігурацією**, виконай команду з клонованого репозиторію:

```bash
sudo bash uninstall.sh --purge
```

**Увага:** параметр `--purge` незворотно видаляє список камер і налаштування.

## Оновлення

Після встановлення оновлення можна запускати з будь-якого каталогу:

```bash
sudo bash /opt/camwall/update.sh
```

Скрипт завантажує останню версію з GitHub, оновлює Python-залежності та перезапускає службу. Робочі `playlist.json` і `settings.json` зберігаються.

## Конфігурація

Робочі файли зберігаються в `/opt/camwall/`:

- `playlist.json` — назви камер та RTSP URL. Шаблон у репозиторії: `playlist.example.json`.
- `settings.json` — налаштування вебінтерфейсу. Шаблон: `settings.example.json`.

Не додавай реальні RTSP URL та паролі до публічного репозиторію.

## Безпека

**Ця версія не має автентифікації.** API налаштувань може передавати RTSP URL та облікові дані браузеру. Не виставляй порт 8080 безпосередньо в інтернет. Обмеж доступ firewall-ом до довіреної LAN або використовуй авторизований reverse proxy.

## Оптимізація та кодеки

За замовчуванням FFmpeg зменшує відео до 640×360 і 10 FPS, кодує в H.264 через `libx264` із цільовим бітрейтом 500 kbit/s та maxrate 600 kbit/s. Серверне перекодування навантажує CPU; на слабких ARM-пристроях багато одночасних камер можуть бути завеликим навантаженням.

H.264 має найкращу сумісність із браузерами. Підтримка H.265/HEVC обмежена. Для першого відкриття сторінки потрібен доступ до CDN `cdn.jsdelivr.net` для завантаження mpegts.js.

## Діагностика

```bash
curl http://127.0.0.1:8080/health
sudo systemctl status camwall
sudo journalctl -u camwall -f
ffmpeg -hide_banner -rtsp_transport tcp -i 'rtsp://USER:PASS@CAMERA/PATH' -t 5 -f null -
```

Не вставляй RTSP URL із паролем у публічні логи чи звернення до підтримки.
